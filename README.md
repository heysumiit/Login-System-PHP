# Login System PHP

### PHP | MySQL | HTML | CSS | JavaScript

A web-based Login System project designed to provide user authentication and account management through a simple interface. The project includes login, registration, user pages, and admin functionality using PHP and frontend technologies.

---

## About

The Login System PHP project demonstrates the implementation of common authentication features in a web application.

It includes PHP files for login, registration, logout, configuration, and user/admin pages, along with CSS styling.

## Features

* User login interface
* User registration form
* Logout functionality
* Separate user and admin pages
* PHP-based server-side functionality
* CSS styling for the interface
* Configuration file for application settings

## Getting Started

### Requirements

* PHP environment such as XAMPP or WAMP
* Web browser
* MySQL database server, if required by the application

### Run Locally

1. Install and start your local PHP environment.
2. Place the project folder inside the server's web directory (for example, `htdocs` in XAMPP).
3. Start Apache and, if the application uses it, MySQL.
4. Open the project in your browser using your local server address.

Example:

```text
http://localhost/Login-System-PHP/
```

Update the URL if your project folder has a different name.

## Note

Database configuration and setup depend on the contents of the project’s `config.php` file and the database implementation.
